# Phonika RU

**Phonika RU** — простое веб-приложение для первых шагов ребёнка в чтении на русском языке. Оно помогает постепенно знакомиться со звуками и буквами, а затем переходить к чтению настоящих слов.

Главная идея приложения — короткие регулярные занятия без перегруженного интерфейса. На экране остаётся только то, что нужно ребёнку прямо сейчас: звук или слово и несколько понятных действий.

## Как устроено обучение

Обучение идёт постепенно. Ребёнок работает с небольшой группой — до **пяти звуков одновременно**. Когда большинство из них уже уверенно знакомы, один освоенный звук заменяется новым, а тот, который пока вызывает трудности, остаётся для повторения.

Чтение развивается параллельно со знакомством со звуками. Приложение показывает ребёнку только те слова, которые становятся ему доступны по мере освоения необходимых звуков и правил. Поэтому не нужно сначала выучивать весь алфавит и только потом начинать читать.

В чтении действует похожий принцип: одновременно предлагается небольшое количество слов. Если ребёнок прочитал слово самостоятельно, взрослый нажимает **«✓ Прочитал сам»**. После нескольких успешных самостоятельных прочтений приложение считает слово освоенным и постепенно добавляет новое. Трудные слова продолжают возвращаться.

## Звуки, а не названия букв

Phonika RU ориентируется прежде всего на звуки речи. При обучении чтению важно связывать букву со звуком, который ребёнок использует при соединении букв в слово, а не только запоминать алфавитное название буквы.

Для каждого звука используется визуальная ассоциация с понятным ребёнку словом и картинкой. Картинку можно показать только при необходимости, чтобы она помогала, но не подсказывала ответ заранее.

Мягкий и твёрдый знаки рассматриваются отдельно как знаки, не имеющие собственного звука.

## Чтение

Слова распределены по этапам сложности. Сначала появляются короткие и простые слова, затем более длинные слова, сочетания согласных и постепенно — новые особенности русского чтения, например **Й**, **Ь**, а позднее **Е, Ё, Ю, Я**.

Уровни задают направление обучения, но приложение сохраняет возможность возвращать уже знакомый материал для повторения.

Если ребёнку трудно прочитать слово, можно воспользоваться кнопкой **«🔊 Помоги прочитать»** или показать картинку. Такое прочтение не засчитывается как самостоятельное.

## Минимум отвлекающих элементов

Интерфейс специально сделан спокойным и минималистичным. Большая буква или слово находятся в центре внимания, а количество кнопок ограничено.

Занятие не рассчитано на долгое время перед экраном. Вместо большого урока ребёнку предлагается небольшая последовательность из нескольких звуков или слов. Идея Phonika RU — **понемногу, регулярно и с постепенным усложнением**.

Гласные и согласные визуально различаются цветом. Родитель также может выбрать стиль написания букв, который ребёнок будет видеть во время занятий.

## Для родителей

В отдельном родительском разделе можно:

- отметить звуки, которые ребёнок уже знает;
- выбрать текущий уровень чтения;
- увидеть короткую подсказку о содержании уровня;
- посмотреть звуки и слова, которые сейчас находятся в работе;
- увидеть уже освоенные звуки и слова;
- выбрать стиль отображения букв.

Если ребёнок уже знает часть букв до начала работы с приложением, начинать всё сначала не требуется — родитель может отметить их как знакомые.

## Адаптивный принцип

Phonika RU не требует от каждого ребёнка двигаться с одинаковой скоростью. Освоенное постепенно уступает место новому, а материал, который пока даётся сложнее, остаётся в текущей группе.

Таким образом, приложение старается поддерживать индивидуальный темп: не перегружать ребёнка большим количеством нового материала и одновременно не заставлять бесконечно повторять то, что уже хорошо знакомо.

## Технически

Phonika RU — статическое веб-приложение на HTML, CSS и JavaScript. Для запуска не требуется сборка или установка отдельного приложения.

Прогресс текущей версии хранится локально в браузере (`localStorage`). Аккаунты и облачная синхронизация пока не используются, поэтому прогресс привязан к конкретному браузеру и устройству.

Для локального запуска можно использовать любой HTTP-сервер, например:

```bash
python -m http.server 8000
```

После этого открыть `http://localhost:8000`.

## Структура проекта

- `index.html` — интерфейс приложения и адаптивные стили;
- `app.js` — логика звуков, чтения, уровней, прогресса и адаптивной ротации;
- `fonts/` — дополнительные шрифты и лицензии.

---

**Phonika RU** — это не попытка дать ребёнку как можно больше материала за одно занятие. Цель приложения — сделать первые шаги к самостоятельному чтению понятными, спокойными и постепенными.
