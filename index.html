Для родителей
Индивидуальный маршрутSound Steps показывает только те слова, для которых ребёнок уже освоил необходимые звуки и правила.

Текущий этап чтения

Уровень задаёт новый навык, а не жёстко ограничивает ребёнка. Слова предыдущих уровней продолжают возвращаться для повторения.

Звуки сейчас

В работе до пяти звуков. После трёх уверенных отметок звук считается освоенным. Когда освоены 4 из 5, один освоенный звук заменяется новым, а трудный остаётся.

Освоенные звуки

Слова сейчас

В работе до пяти доступных слов. Слово открывается только тогда, когда освоены все необходимые для него звуки. После трёх самостоятельных прочтений оно считается освоенным. При 4 освоенных словах появляется новое, а трудное остаётся.
